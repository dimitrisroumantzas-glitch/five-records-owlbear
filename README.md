# Hollow Archive — The Five Records

Image-based Owlbear Rodeo extension for **Echoes of the Forgotten Age**.

## Visual rule
The extension is built around player-facing D&D campaign imagery rather than generic software UI:
- a dark fantasy Hollow Archive scene,
- five physical stone Record cards,
- five carved activation glyphs,
- an opened-Archive reveal scene.

## Canonical puzzle
Phase One: `KEY → QUILL → SEAL → EYE → FLAME`

Inner Index:
- KEY = IV
- QUILL = II
- SEAL = V
- EYE = I
- FLAME = III

Phase Two: `EYE → QUILL → FLAME → KEY → SEAL`
