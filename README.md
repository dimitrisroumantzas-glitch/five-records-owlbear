# Five Records — Hollow Archive

Owlbear Rodeo extension for the **Echoes of the Forgotten Age** campaign.

## Features
- Shared two-phase puzzle synced between GM and players.
- Phase One solution: `KEY → QUILL → SEAL → EYE → FLAME`
- Index reveal: KEY=IV, QUILL=II, SEAL=V, EYE=I, FLAME=III
- Phase Two solution: `EYE → QUILL → FLAME → KEY → SEAL`
- Three failed Phase Two attempts alert the Archive.
- GM controls: Reset, Reveal Phase 2, Open Archive.
- Touch-friendly drag/tap interaction.
- Persistent shared state through Owlbear room metadata.

Add the manifest URL above as a custom extension in Owlbear Rodeo, then enable **Five Records — Hollow Archive** in the room.
