# Hollow Archive — The Five Records

Owlbear Rodeo extension for **Echoes of the Forgotten Age**.

## Canonical puzzle

### Phase One — Provenance
Arrange the five Records in this order:

`KEY → QUILL → SEAL → EYE → FLAME`

Canonical clues:
- KEY: I stood before the Quill.
- QUILL: The Seal followed immediately after me.
- SEAL: I stood before the Eye.
- EYE: My place was neither first nor last.
- FLAME: Exactly one place stood between the Seal and me, and I stood after the Eye.

### Inner Index reveal
- KEY = IV
- QUILL = II
- SEAL = V
- EYE = I
- FLAME = III

### Phase Two — Index
Activate all five glyphs in Roman-numeral order:

`EYE → QUILL → FLAME → KEY → SEAL`

Failure escalation:
1. First failure: glyphs reset.
2. Second failure: a deep stone knock answers from within the mountain.
3. Third failure: white light floods the seal and the Hollow Archive registers the party's presence.

## Features
- Shared state synchronized between GM and players.
- Touch-friendly drag/tap Phase One interaction.
- Five-step Phase Two glyph activation.
- Persistent room metadata.
- GM controls: hints, reveal Inner Index, force open, reset.
- Crisp CSS/vector presentation with no low-resolution embedded puzzle art.
- State version 4 resets incompatible v3 puzzle state automatically.

## Install
Manifest URL:

`https://dimitrisroumantzas-glitch.github.io/five-records-owlbear/manifest.json`

Add it as a custom extension in Owlbear Rodeo and enable it in the room.
