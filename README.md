# Hollow Archive — Οι Πέντε Καταγραφές

v9.0.0

Ροή:
1. Οι παίκτες βλέπουν πέντε μεγάλες, ξεχωριστές πέτρινες επιγραφές με τις ενδείξεις, σε ανακατεμένη σειρά.
2. Τοποθετούν τις πέντε πέτρες στη σωστή σειρά: KEY → QUILL → SEAL → EYE → FLAME.
3. Το background ΔΕΝ αλλάζει. Πάνω στις ίδιες πέτρες εμφανίζονται IV, II, V, I, III.
4. Οι παίκτες πατούν τις ίδιες πέτρες με σειρά EYE → QUILL → FLAME → KEY → SEAL.
5. Μόνο μετά τη σωστή δεύτερη σειρά εμφανίζεται η τελική εικόνα.

Δεν υπάρχει αυτόματη μετάβαση μεταξύ των δύο σταδίων του γρίφου.
